# Stack Tecnológica

## Linguagem Principal
**Python first** — fortalece candidatura para posições SAP, Data, Automation, Business Systems, Application Support, Analytics.

## Stack

| Camada | Tecnologia |
|--------|-----------|
| Framework API | FastAPI |
| ORM | SQLAlchemy |
| Validação de dados | Pydantic |
| Banco de dados | PostgreSQL |
| Análise de dados | Pandas |
| Visualização | Plotly (Python + JS) |
| Templates | Jinja2 |
| Frontend | HTML + CSS + JavaScript + Plotly.js |

## Por que NÃO React?

O valor do projeto está no **processo → dados → regras → integração → análise**, não no frontend. Um dashboard HTML com Jinja2 + Plotly.js é suficiente e mantém o foco no domínio ERP.
